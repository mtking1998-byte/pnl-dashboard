راهنمای آپلود سایت نت‌لینک
============================

این بسته شامل فایل‌های آمادهٔ سایت است:
- index.html      → صفحهٔ اصلی سایت
- css/style.css   → استایل سایت
- js/app.js       → اسکریپت تعاملات
- .htaccess       → تنظیمات سرور آپاچی (اختیاری ولی توصیه‌شده)

────────────────────────────────
روش ۱: آپلود روی هاست (cPanel)
────────────────────────────────
1. وارد cPanel هاست خود شوید.
2. File Manager را باز کنید و به پوشهٔ public_html بروید.
3. فایل netlink-website.zip را آپلود کنید.
4. روی فایل زیپ راست‌کلیک کرده و Extract را بزنید.
5. مطمئن شوید index.html در ریشهٔ public_html قرار گرفته باشد.
6. آدرس دامنهٔ خود را در مرورگر باز کنید — سایت نمایش داده می‌شود.

نکات:
- اگر هاست شما Apache است، فایل .htaccess به‌صورت خودکار فعال می‌شود.
- برای فعال‌سازی HTTPS، خطوط مربوط به Rewrite را در .htaccess از حالت کامنت خارج کنید.
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ نیازی به آپلود فونت نیست.

────────────────────────────────
روش ۲: وردپرس
────────────────────────────────
فایل netlink-theme.zip یک قالب آمادهٔ وردپرس است:
1. وارد پیشخوان وردپرس شوید.
2. نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته.
3. فایل netlink-theme.zip را انتخاب و «اکنون نصب کن» را بزنید.
4. روی «فعال کردن» بزنید — صفحهٔ اصلی سایت همین طراحی را نمایش می‌دهد.
(محتوای بخش‌ها داخل front-page.php قالب قابل ویرایش است.)
